# judgment-critic
Companion skill for power-core / hermes-extensions / any vision skill. Install: `python install.py --skills-dir ~/.hermes/skills`
Scorecard that rejects vague praise, a hostile-pass requirement, fixed PASS/REVISE/REJECT thresholds, and calibration against
the user's own verdicts. It improves process and consistency; it cannot exceed the underlying model's ability to see.
